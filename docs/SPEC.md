# フサキビーチリゾート 家族旅行アプリ 仕様書

## 概要
石垣島「フサキビーチリゾート ホテル&ヴィラズ」滞在中に家族(大人のみ)が
スマートフォンで使う旅行コンパニオンアプリ。

## 技術方針
- **単一ページのモバイルWebアプリ**(`index.html` + `app.js` + `styles.css` + `data/resort-data.js`)
- ビルドツール不使用。バニラJS。外部ライブラリなし(CDN依存なし)
- PWA風: `manifest.webmanifest` を用意し「ホーム画面に追加」で全画面利用可
- 個人データ(スケジュール編集・チェックリスト・メモ)は `localStorage` に保存
- 表示言語: 日本語
- 対象画面幅: 360〜430px(モバイルのみ)。下部タブバーでナビゲーション
- ダーク/ライト両テーマ対応(prefers-color-scheme)

## 画面(下部タブ 5つ)
1. **ホーム** 🏖
   - 今日の日付・滞在何日目か(旅行期間は設定で編集可)
   - 石垣島の現在天気と7日間予報(Open-Meteo API、キー不要、fetch失敗時は非表示でグレースフルに)
     - 座標: lat 24.3448, lon 124.1572(フサキ付近: 24.366, 124.113 を使用)
   - 日の出・日の入り時刻(Open-Meteo daily sunrise/sunset)→「サンセットまであと◯時間」表示
   - 今日のスケジュール(スケジュールタブのデータから当日分を抜粋表示)
2. **スケジュール** 📅
   - 日付ごとの予定リスト(時刻・タイトル・メモ)。追加/編集/削除可
   - localStorage保存。初期サンプルは空
3. **リゾート情報** 🏨
   - `data/resort-data.js` の内容をアコーディオン/カード表示
   - カテゴリ: レストラン・バー / プール&ビーチ / アクティビティ / 館内施設 / 周辺スポット / アクセス・交通
   - 各項目: 名前、説明、営業時間、場所、備考、(あれば)電話番号・URL・Googleマップリンク
4. **チェックリスト** ✅
   - 持ち物リスト(初期テンプレート入り: ビーチリゾート向け)+ 自由追加
   - 「やることリスト」セクションも(例: 帰りの飛行機チェックイン)
   - チェック状態・追加項目は localStorage 保存。リセットボタンあり
5. **メモ** 📝
   - フリーメモ(複数メモ、タイトル+本文)
   - お土産リスト(誰に・何を・済みチェック)
   - 緊急連絡先・便利リンク集(resort-data.js の links セクションから表示)

## データスキーマ: `data/resort-data.js`
`window.RESORT_DATA = {...}` を定義する。**リサーチ担当はこのファイルだけを作る。**

```js
window.RESORT_DATA = {
  updatedAt: "2026-09-14",
  hotel: {
    name: "フサキビーチリゾート ホテル&ヴィラズ",
    address: "...",
    tel: "...",
    checkIn: "15:00", checkOut: "11:00",
    mapUrl: "https://maps.google.com/?q=...",
    notes: ["..."]
  },
  categories: [
    {
      id: "dining",            // dining | pool_beach | activities | facilities | nearby | access
      title: "レストラン&バー",
      icon: "🍽",
      items: [
        {
          name: "...",
          description: "...",
          hours: "...",         // 営業時間(不明なら null)
          location: "...",      // 館内の場所 or 住所
          tel: null,            // あれば
          url: null,            // 公式ページ等
          mapUrl: null,         // 周辺スポットはGoogleマップリンク
          tips: null            // 予約要否・混雑情報などの一言
        }
      ]
    }
  ],
  links: [
    { label: "石垣島の天気(気象庁)", url: "...", note: null },
    { label: "タクシー(◯◯交通)", tel: "...", url: null, note: "ホテルまで空港から約35分" }
  ],
  emergency: [
    { label: "かりゆし病院(石垣市)", tel: "...", note: "..." }
  ]
};
```

## デザイン
- リゾート感: 海/サンセットを想起する配色(ティール〜サンセットオレンジのアクセント)
- 大きめタップターゲット(44px以上)、システムフォント
- ヘッダーは薄く、コンテンツ優先。safe-area-inset 対応(iPhoneノッチ)

## 受け入れ基準
- スマホ幅で横スクロールが発生しない
- オフライン(API失敗)でも天気以外は全機能動作
- localStorage が使えない環境でも例外で落ちない(try/catch)
- 全タブが1秒以内に切替(SPAとしてJSでタブ切替)
