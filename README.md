# フサキビーチリゾート 家族旅行アプリ 🏖

石垣島「フサキビーチリゾート ホテル&ヴィラズ」滞在中に家族で使う、モバイル専用の旅行コンパニオンアプリです。

## 機能

- **ホーム**: 石垣島の現在天気・7日間予報・日の出/日の入り(サンセットカウントダウン)、滞在何日目か、今日の予定
- **スケジュール**: 日付ごとの旅程管理(追加・編集・削除)
- **リゾート情報**: 館内レストラン、プール&ビーチ、アクティビティ、周辺スポット、アクセス情報
- **チェックリスト**: 持ち物・やることリスト(テンプレート付き)
- **メモ**: フリーメモ、お土産リスト、緊急連絡先・便利リンク

## 使い方

ビルド不要の静的Webアプリです。

```sh
python3 -m http.server 8000
# スマホのブラウザで http://<PCのIP>:8000 を開く
```

GitHub Pages などの静的ホスティングにそのまま置けます。
スマホのブラウザで開いて「ホーム画面に追加」すると全画面アプリとして使えます。

- スケジュール・チェックリスト・メモは各端末の localStorage に保存されます(共有はされません)
- 天気は [Open-Meteo](https://open-meteo.com/) API(キー不要)を利用。オフラインでも天気以外は動作します
